## Features

- **Standard & Scientific Calculator**: Perform basic arithmetic, trigonometric functions, logarithms, and more.
- **Graphing Calculator**: Plot multiple functions simultaneously, with zoom, pan, and dynamic axis scaling.
- **Unit Converter**: Convert between various units for length, mass, temperature, and more.
- **Programmer's Calculator**: Work with different number bases (HEX, DEC, OCT, BIN) and perform bitwise operations.
- **Calculus Tools**: Numerically compute derivatives and definite integrals of functions.
- **AI-Powered Assistance**: Leverage Google's Gemini AI for solving complex problems and getting step-by-step explanations.
- **Responsive Design**: A clean, modern UI that works seamlessly on both desktop and mobile devices.


## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Create a `.env.local` file by copying the example: `cp .env.example .env.local`
3. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
4. Run the app:
   `npm run dev`
